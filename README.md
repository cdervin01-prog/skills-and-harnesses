# Skills and Harnesses

Blank frameworks — no project facts, no secrets. Fill in per problem.

**Harness = laws. Skill = direction for this job.**
Laws live in `harness/LAWS.md` (keep slim). Skills do not rewrite them.

```
harness/
  LAWS.md              — always-on gates, tree, springs
skills/
  troubleshooter/      — map for a failing system
  laneway-harness/     — map for bounded token-steering
```

## Install

```sh
mkdir -p ~/.agents/skills
cp -r skills/* ~/.agents/skills/
# Put harness/LAWS.md in whatever your runtime actually injects every turn.
```

A skill file cannot enforce a lock. Earned prunes become rules only if the
runtime logs them, injects the dead list, and blocks re-entry. Until then,
LAWS.md is the poster; the wrapper is the bouncer.

## Troubleshooter

Local first. Web only at a logged dead end. Narrow warrant. Scout then troop.
Fat research packet / thin leads / probe ledger. Prune audit at reset.
R1 evidence-only. R2 cheapest-test-first. R3 reset bound. R4 token ceiling.

Test that matters: plant a fault you already know; fail the run if it buries
the winning branch without an honest probe.

## Laneway Harness

Nudge-not-knife constitution. Answers emerge. Coverage grid. App-layer gate.
